# 앱 정체성 — 이름 제안

## 1. 출발점

| 항목 | 내용 |
|---|---|
| 문제 | "만다라트"는 오타니 쇼헤이 · 9×9 표를 아는 사람만 얼핏 인지하는 단어 |
| 개인 용도 | 목표 설정 · 과정 설계를 위한 **시각적 자료** |
| 기업 용도 | 팀 단위 성과 분석 · 방향성 제시를 위한 **시각적 자료** |
| 담고 싶은 뜻 | **[목적을 향해 가기 위한]** — 추상적이거나 상징적인 단어 |

## 2. 키워드 조사에서 얻은 힌트

[키워드 조사](research/keywords-2026-11.md) 결과, 사람들은 단어마다 다른 층위로 말합니다.

```
목적 · 삶   →  "왜"      의미 · 방향           ← 이름이 담아야 할 층위
꿈 · 목표    →  "무엇을"   일 · 도전 · 버킷리스트  ← 앱 안의 81칸이 담당
```

이름은 **"무엇을"(할 일 목록)** 이 아니라 **"왜 · 어디로"(방향)** 를 말해야 개인과 기업 모두에 통합니다.
할 일 앱 · 습관 앱과 구분되는 지점도 여기입니다.

## 3. 후보

### ⭐ 추천 1. **North Nine** (노스나인)
| | |
|---|---|
| 뜻 | **North** — 북극성, 길을 잃지 않게 하는 방향 · **Nine** — 9개의 방향, 9×9 구조 |
| 한 줄 | **"방향을 정하면, 아홉 갈래 길이 보인다"** |
| 개인 | 나의 North(핵심 목표)와 8개의 길 |
| 기업 | 팀의 North를 정렬한다 — 경영의 "North Star 지표" 개념과 자연스럽게 연결 |
| 장점 | 앱의 **구조(9)** 와 **의미(방향)** 를 한 이름에 담음 · 발음 쉬움 · 조어라 검색 시 겹치는 앱 없음 |
| 주의 | "North Star"류 이름은 많음 → 반드시 "Nine"까지 붙여 써야 구분됨 |

### 추천 2. **지향** (志向 · Jihyang)
| | |
|---|---|
| 뜻 | **뜻 지(志) + 향할 향(向)** — "뜻이 향하는 곳". 요청하신 [목적을 향해 가기 위한] 의 거의 직역 |
| 한 줄 | **"뜻이 향하는 곳을, 81칸으로"** |
| 개인 | 내 삶의 지향점 |
| 기업 | "조직의 지향" · "팀 지향점 정렬" — 한국 기업 보고서에서 이미 쓰는 단어 |
| 장점 | 한국 사용자에게 설명이 필요 없음 · 한자 의미가 정확 · 격이 있음 |
| 주의 | 해외 사용자에게는 의미 전달이 안 됨 · 일반 명사라 상표 등록이 어려울 수 있음 |

### 추천 3. **Telos** (텔로스)
| | |
|---|---|
| 뜻 | 그리스어 **"궁극의 목적, 도달점"** — 아리스토텔레스 철학의 핵심 개념 |
| 한 줄 | **"모든 계획은 목적에서 시작한다"** |
| 장점 | 가장 상징적 · 철학적 · 짧음 |
| 주의 | ❗ 이미 같은 분야 앱이 있음 — [Telos: Life on Purpose](https://apps.appfollow.io/ios/telos-life-on-purpose/6499280663?country=ca), [Telos – Focus & Habit Tracker](https://apps.apple.com/gb/app/telos-focus-habit-tracker/id6744418601). 단독 사용은 비추천 |

### 그 밖의 후보
| 이름 | 뜻 | 한 줄 평 |
|---|---|---|
| Azimuth (아지무스) | 방위각 — 목표를 향한 정확한 각도 | 의미는 좋으나 한국어 발음 · 기억이 어려움 |
| Waypoint (웨이포인트) | 목적지로 가는 경유지 | 81칸 = 경유지라는 비유는 좋지만 "과정"만 강조됨 |
| Vector (벡터) | 방향 + 크기 = 목적 + 실행력 | 기업 성과(크기)와 방향을 함께 담지만 너무 흔한 단어 |
| 나침 | 나침반의 바늘 | 친근하지만 기업용으로는 가벼움 |

## 3-1. 별 · 북극성 · 지표 조합 후보 5선 (2026-11-01)

North Nine 방향 확정 후, **[북극성] [별] [Star] [지표]** 를 조합해 한국인 · 외국인 모두 바로 읽히는 이름으로 추렸습니다.

| # | 이름 | 한국어 표기 | 조합 | 뜻 · 느낌 | 개인 / 기업 | 겹침 확인 |
|---|---|---|---|---|---|---|
| 1 | ⭐ **North Nine** | 노스나인 | 북극성 + 9 | 북극성(방향) 하나와 9갈래 길 — 구조와 의미를 동시에 | 나의 North / 팀의 North 정렬 | 같은 이름 앱 없음 |
| 2 | **StarMark** | 스타마크 | 별 + 지표(Mark) | "별을 지표 삼아" — 목표를 표시하고 진척을 찍는 느낌 | 개인 기록 · 기업 KPI 표식 모두 자연스러움 | 목표 앱 중 없음 |
| 3 | **NineStar** | 나인스타 | 9 + 별 | 핵심 1 + 세부 8 = **9개의 별**로 이루는 별자리 | 개인 친화적 · 아이콘 만들기 쉬움 | 목표 앱 중 없음 |
| 4 | **Polaris Nine** | 폴라리스 나인 | 북극성(라틴어) + 9 | 천문학 이름이라 고급스럽고 국제적 | 기업 제안서에 어울림 | "Polaris – High School Planner" 학생용 앱 존재 → **Nine** 필수 |
| 5 | **North Index** | 노스 인덱스 | 북극성 + 지표(Index) | 방향을 숫자로 — 성과 지표 느낌이 강함 | **기업 · 팀 성과 분석**에 특히 강함 | 목표 앱 중 없음 |

**피해야 할 이름 (이미 유명하거나 같은 분야 앱 존재)**
- North Star — 같은 이름의 목표 · 습관 앱 존재 ([App Store](https://apps.apple.com/app/id1480448999))
- Polestar — 볼보 계열 전기차 브랜드
- Stellar — 같은 이름의 목표 · 습관 앱 존재 ([App Store](https://apps.apple.com/app/id6758196270))
- GuideStar — 미국 비영리 단체 정보 서비스로 유명

**추천 순위:** ① North Nine (구조 + 방향, 가장 균형) ② StarMark (가장 쉬움, 지표 의미 직관적) ③ North Index (기업 용도를 앞세울 때)

## 4. 제안하는 조합

> **North Nine** (영문 브랜드) + **지향** (한국어 슬로건 · 설명)
>
> **North Nine — 뜻이 향하는 곳을, 아홉 갈래로**

- 앱 이름 · 아이콘 · 도메인(나중에): **North Nine**
- 한국어 소개 · 기업 제안서: "**지향점**을 정하고 81칸으로 설계하는 도구"
- **"만다라트"는 버리지 않고 방법론 이름으로 유지**: "만다라트 방식의 81칸 설계" — 아는 사람에게는 신뢰를, 모르는 사람에게는 앱 안에서 설명
- 기존 "만다라트 시그니처" 테마 → "**North Nine 시그니처**" 로 변경 가능
