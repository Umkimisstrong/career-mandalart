## 데이터
`Store.events: CalEvent[]` — `{ id, date 'YYYY-MM-DD', time? 'HH:MM', title, dur?, alarm?, done?, updatedAt }`.
- `alarm` = 몇 분 전에 알릴지 (0 = 그 시각, 없으면 알림 없음). 시각이 없는 일정은 그날 9시 기준.
- 반복 점검 · 완료 기록은 새로 저장하지 않고 목표 칸의 `routine` · `log` 를 달력에 그대로 보여 준다.
- 백업 코드(JSON)에 들어가고 같은 id 는 덮어쓴다. QR · 팀 코드에는 넣지 않는다.

## 한 줄 형식
`날짜 시간 할 일 ~얼마나 !알림` — 순서 자유, 할 일 말고는 빼도 된다. 날짜를 빼면 달력에서 고른 날.

| 칸 | 알아듣는 말 |
|---|---|
| 날짜 | `11/20` · `11.20` · `2026-11-20` · `11월 20일` · `오늘` · `내일` · `모레` · `글피` · `토요일` · `이번 주 금` · `다음 주 토요일` · `20일` |
| 시간 | `19:00` · `7시` · `오후 3시` · `오전 10시 30분` · `3시 반` · `저녁 7시` (오전/오후 없는 1~6시는 오후로 봄) |
| 얼마나 | `~1시간` · `~30분` · `~1시간 30분` · `~1.5시간` |
| 알림 | `!` 그 시각 · `!30분` · `!1시간` (전) |

한 글자 요일(「월」)만으로는 날짜로 보지 않는다 — 「월 정산」 같은 할 일과 헷갈려서 「요일」이나 「~주」를 붙인다.

## 알림 길 넓히기 (예정)
알림을 보내는 길(channel)이 늘어도 일정 데이터(`alarm` = 몇 분 전)는 그대로 쓴다.

| 길 | 지금 | 필요한 것 |
|---|---|---|
| 휴대폰 푸시 | 로컬 알림(앱이 예약) | 앱을 닫아도 울림. 웹 앱(iPhone)은 열려 있을 때만 → .ics 로 기기 캘린더에 |
| Windows | 데스크톱 앱이 켜져 있으면 Windows 알림 | 트레이에 살아 있으면 계속 울림 |
| 메일 | 없음 | 정해진 시각에 보내는 **서버**(예약 실행) + 메일 발송 서비스 + 사용자 메일 주소 저장 · 동의 |
| 알림톡 | 없음 | 카카오 비즈니스 채널 · 발송 대행사 계약(건당 유료) · 템플릿 심사 · 서버 · 전화번호 저장 · 동의 |

메일 · 알림톡은 지금의 「서버 없이 · 기기에만 저장」 원칙을 처음으로 넘는 일이다. 개인정보(주소 · 전화번호)를 서버에 두게 되고, Vercel 무료(Hobby) 플랜은 상업 이용이 안 되므로 판매 시작 이후 호스팅 결정과 함께 정한다.
